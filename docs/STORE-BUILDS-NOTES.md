# Notes for the store builds (iOS and Android)

Parked on purpose. The redesign ships to the web first (therapylog.app/app);
the App Store and Play Store builds come after, and need changes to be listed
at all. Nothing here has been done. This is the list to start from.

The native apps are built in `therapylog/therapylog-app`. Its `www/index.html`
is generated by `scripts/build-shell.js` from `vendor/app.html` (a copy of this
repo's `app.html`, pulled by `scripts/sync-app.js`) plus `shell/overrides/*.js`
and `shell/native.js`. `vendor/app.html` there is still the 5 September copy.

## Before the next `sync-app.js`

- **Delete `shell/overrides/importData.js` and `shell/overrides/sd.js`.** Both
  are frozen copies of the pre-redesign functions, with no native-only branch.
  If they stay, the generated build replaces this repo's `importData` and `sd`
  with the old ones, and restoring a backup on a phone silently drops the
  redesign's keys (`doseChanges` today; `protocol`, `settings` and `v` once
  the new screens write them). Found by the Phase 1 review, finding 12.
  After deleting, run `node scripts/build-shell.js` and check that
  `importData` in `www/index.html` contains the `tlImportModel(` call.
- Review every other file in `shell/overrides/` the same way. The shell README
  says most are drift, not platform differences. Any override of a function the
  redesign changed (for example `renderPKLevels`, `scheduleAllReminders`,
  `checkAndFireReminder`) has to be retired or rewritten, or the store build
  runs old behaviour under the new screens.
- Copy the new font files into `www/vendor/fonts/`: `inter-latin-400.woff2`,
  `inter-latin-500.woff2`, `inter-latin-ext-400.woff2`,
  `inter-latin-ext-500.woff2`, `phosphor-regular.woff2`,
  `phosphor-fill.woff2`, with `Inter-LICENSE.txt` and
  `Phosphor-LICENSE.txt`. The stylesheet loads them from `/vendor/fonts/`.
  Without them the app falls back to the system font and the icons are blank.

## Notifications

- The redesign sends one alert per round, not one per compound.
  `src/logic/alerts.js` has the text and `tlAlertPlan(protocol, entries, from,
  days)` returns `{ at, alert }` for every round to schedule.
  `TLNative.reschedule` in `shell/native.js` still schedules per compound from
  `proto` and `reminderTimes`; it needs to schedule from `tlAlertPlan` instead.
- The round alert has two actions, "Log {round} round" and "Open"
  (LocalNotifications action types). "Log round" should call `tlLogRound` and
  then show the "logged" notification from `tlRoundLoggedAlert`, with Undo.
- The discreet variant hides compound names on the lock screen.
- The supply alert comes from `tlSupplyAlerts`.

## App Store

- Camera and photo library usage strings in `ios/App/App/Info.plist`
  (`NSCameraUsageDescription`, `NSPhotoLibraryUsageDescription`, and
  `NSPhotoLibraryAddUsageDescription` if photos are saved). No Info.plist is
  committed today, so the camera crashes the app. Commit the `ios` folder or
  write the keys from a post-sync script.
- Restore Purchases: `tlRestorePurchases()` already starts the App Store
  restore on iOS. Settings (screen 5b) shows the row permanently.
- No bring-your-own-key plan on iOS; both upgrade gates sell Pro.
- Steroid and cycle content is stripped from store builds except in the
  Encyclopedia. That needs a build flag; the web build keeps everything.

## Play Store

- Its own price point and feature set, decided later.
- The bring-your-own-key plan is allowed here.
